## Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_LINK
```

**2. Navigate to the project directory**

```bash
cd Project-2
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the server**

```bash
node server.js
```
